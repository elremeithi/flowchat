## What's new in 1.13.0

- **Share button under every chat message.** Text, photos, videos and files can go straight to another app (WhatsApp, email, Drive and so on) through the phone's share sheet.
- In the Android app, the file is fetched from your server first. Only the latest shared file is kept in the app's cache.
- In a browser, sharing needs the site on HTTPS and a browser that supports it, such as Chrome on Android or Windows, or Safari. Where it isn't available, the button isn't shown. Files over 200 MB can't be shared from a browser: use Download.

## Upgrading

- **Server (Unraid)**: update the Flowchat container (use *force update* in Advanced View if Unraid says there's no update). Settings should then show *Server version 1.13.0*.
- **Android**: install `Flowchat-1.13.0.apk` over the current app. The Share button only shows in the app once this version is installed.
