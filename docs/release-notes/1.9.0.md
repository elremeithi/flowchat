## What's new in 1.9.0

- **Notes support Markdown.** A note opens showing its formatted text: headings (`#`), **bold**, *italic*, ~~strikethrough~~, `code` and code blocks, links, quotes, lines (`---`), and bulleted or numbered lists, including nested ones.
- **To-do lists you can tick.** Write `- [ ] Milk` for a box you can tick straight from the formatted view. Ticking it saves the note and syncs to your other devices.
- **Edit and Done.** Tap **Edit**, or tap the text, to change the note; **Done** shows it formatted again. New and empty notes open ready to write.
- The notes list shows titles and snippets without Markdown symbols.

## Upgrading

- **Server (Unraid)**: update the Flowchat container (use *force update* in Advanced View if Unraid says there's no update). Settings should then show *Server version 1.9.0*.
- **Android**: install `Flowchat-1.9.0.apk` over the current app (optional: the change comes from the server).
