## What's new in 1.12.0

- **Lock the QR codes with a PIN.** Set a 4-digit *QR codes PIN* (`CODES_PIN`) in the container settings, and Flowchat asks for it before showing QR codes. It's asked once each time the app or browser tab is opened, and it also covers the codes kept on a device for use without a connection.
- **Forgot the PIN?** Change or clear it in the container settings and restart the container.
- After 5 wrong tries, you have to wait before trying again.
- The PIN keeps codes from casual view on an unlocked phone or computer. It isn't encryption.

## Upgrading

- **Server (Unraid)**: update the Flowchat container (use *force update* in Advanced View if Unraid says there's no update). To set the PIN, edit the container. If there's no *QR codes PIN* field, choose *Add another Path, Port, Variable, Label or Device*, then pick *Variable*, enter the key `CODES_PIN` and enter your 4 digits as the value. Settings should then show *Server version 1.12.0*.
- **Android**: install `Flowchat-1.12.0.apk` over the current app. The QR codes tab in the main screen is locked with the server update alone. The app's own QR screens (the home-screen shortcut and the screen used without a connection) need this app version to be locked.
