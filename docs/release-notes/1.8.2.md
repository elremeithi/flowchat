## What's new in 1.8.2

- **New section order: Notes · Chat · QR codes.** Chat is in the middle, so Notes is one swipe right and QR codes one swipe left.
- **Flowchat always opens on Chat**, in the app and in the browser, instead of the last section you had open. Links to a single note or code still open that note or code.

## Upgrading

- **Server (Unraid)**: update the Flowchat container (use *force update* in Advanced View if Unraid says there's no update). Settings should then show *Server version 1.8.2*.
- **Android**: install `Flowchat-1.8.2.apk` over the current app. The new order and opening on Chat come from the server, so they also work with the app you have now.
