Self-hosted chat, notes, QR codes and file drop for your server, with an Android app.

## New since 1.0.0

- **Tabs for Chat, Notes and QR codes**, synced live across every signed-in browser and phone.
- **Notes**: save as you type, search, and a warning when another device changed the same note.
- **QR codes**: keep tickets, Wi-Fi details, links and cards; show one full screen to another phone or scanner. Add by typing, or from a photo (QR codes are redrawn sharply; other codes are kept as the picture).
- **QR codes in the Android app**: stored encrypted on the phone, usable offline, and synced both ways with the server.
- **Lost phone protection**: codes are kept on the server, and removed codes stay in *Recently removed* for 30 days.
- **Everything stored is encrypted with your password** (messages, notes, files, codes, devices, webhooks).
- **Android app**: screenshots and screen recording blocked (switch in the app's settings); full brightness while a code is shown; crash report on the next start if the app ever closes unexpectedly.
- **Settings** shows the server and app versions.

## Upgrading

- **Server (Unraid)**: update the Flowchat container. The image `ghcr.io/elremeithi/flowchat:latest` already contains 1.6. Settings should then show *Server version 1.6*.
  - Set a long **Password** before starting: it also unlocks your data and can't be recovered.
  - Coming from a setup that used `ENCRYPTION_KEY`: keep it set for one start, then remove it.
- **Android**: install `Flowchat-1.6.0.apk` over the current app (same signing key), then close and reopen the app.
