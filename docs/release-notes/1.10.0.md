## What's new in 1.10.0

- **Notes read Nextcloud's Markdown.** Notes now show everything Nextcloud's Text editor writes: tables, callouts (`::: info`, `success`, `warn`, `error`), collapsible details, ==highlight==, __underline__, images from web links, front matter, backslash line breaks and escaped characters.
- **Paste from Nextcloud keeps the formatting.** Copy from a Nextcloud note (or a web page or document) and paste it into a Flowchat note while editing: headings, bold, lists, to-dos, tables, callouts and links are saved as Markdown, written the way Nextcloud writes it. Text that's already Markdown is pasted as it is.
- To-dos inside quotes and callouts can be ticked too.
- Note: `__text__` now means underline, as it does in Nextcloud. Use `**text**` for bold.

## Upgrading

- **Server (Unraid)**: update the Flowchat container (use *force update* in Advanced View if Unraid says there's no update). Settings should then show *Server version 1.10.0*.
- **Android**: install `Flowchat-1.10.0.apk` over the current app (optional: the change comes from the server).
