## What's new in 1.11.0

- **Notes are edited in their formatted form, like in Nextcloud.** Opening a note puts you straight into it, ready to type. There's no Edit button and no need to tap the text first.
- **Markdown as you type.** At the start of a line, type `# ` for a heading (`## ` for a smaller one), `- ` for a list, `1. ` for a numbered list, `[] ` for a to-do and `> ` for a quote. Ctrl+B, Ctrl+I and Ctrl+U work on a keyboard. Other Markdown you type, like `**bold**`, shows formatted once you leave the note.
- **To-dos:** tap the box to tick it. Enter adds the next to-do, Enter on an empty one ends the list, and Backspace at its start turns it back into a plain line. Tab and Shift+Tab move list items in and out.
- **Pasting** from Nextcloud, a web page or a document drops in formatted, and is saved as Markdown in Nextcloud's style.
- Tapping a link opens it.
- Notes are still saved as Markdown, so they read the same in Nextcloud.

## Upgrading

- **Server (Unraid)**: update the Flowchat container (use *force update* in Advanced View if Unraid says there's no update). Settings should then show *Server version 1.11.0*.
- **Android**: install `Flowchat-1.11.0.apk` over the current app (optional: the change comes from the server).
